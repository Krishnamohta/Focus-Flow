
# FocusFlow - Student Productivity Chrome Extension

FocusFlow is a lightweight Chrome extension designed to help students
manage study sessions, organize daily tasks, and track their progress.

## Features

- 25-minute Pomodoro focus timer
- 5-minute break timer
- Start, pause, and reset controls
- Add, complete, and delete tasks
- Daily task completion progress bar
- Persistent storage using Chrome Storage API
- A pastel lavender and pink interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chrome Extension Manifest V3
- Chrome Storage API

## Installation

1. Download or clone this repository.
2. Open Google Chrome and visit chrome://extensions.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the FocusFlow project folder.
6. Click the FocusFlow icon to open the dashboard.

## Project Purpose

FocusFlow provides students with a simple, distraction-free way
to organize study goals and manage focused work sessions.
